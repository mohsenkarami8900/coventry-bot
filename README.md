# ربات قیمت پوند - کانال Coventryexchange

## راه‌اندازی (یک‌بار)
1. در تلگرام به @BotFather پیام بدهید، `/newbot` بزنید و **توکن** را بگیرید.
2. ربات را در کانال `@Coventryexchange` **Admin** کنید (با اجازه‌ی ارسال پیام).
3. یک ریپازیتوری **خصوصی** در GitHub بسازید و همین پوشه را در آن آپلود کنید (شامل `.github/workflows/daily.yml`).
4. در GitHub: Settings > Secrets and variables > Actions > New repository secret
   - `BOT_TOKEN` = توکن ربات
   - `ADMIN_CHAT_ID` (اختیاری) = آیدی عددی چت شخصی شما با ربات، تا اگر قیمت خوانده نشد به شما خبر بدهد
5. تب **Actions** > "Daily GBP price" > Run workflow. با گزینه‌ی `dry_run = 1` فقط تست می‌شود و چیزی در کانال نمی‌رود؛ برای تست واقعی `dry_run` را خالی بگذارید.

## نحوه کار
- هر روز 10:00 به وقت لندن (تغییر ساعت تابستانی/زمستانی خودکار است).
- دوشنبه تا شنبه: قیمت پوند > رند به پایین تا ۱۰,۰۰۰ ریال > تبدیل به تومان > کسر ضریب‌ها > ارسال.
- یکشنبه: پیام تعطیلی + نکته کوتاه (در `bot.py` مقدار `USE_TIPS = False` نکته‌ها را حذف می‌کند).
- اگر tgju قیمت را نداد، قیمتی ارسال نمی‌شود و (در صورت تنظیم) به ادمین خبر می‌دهد. همیشه می‌توانید با Run workflow و پر کردن `manual_price_rial` قیمت را دستی بدهید.

## تنظیمات در bot.py
`OFFSETS` (ضرایب کسر به تومان)، `TETHER_BUY/SELL`، `PHONE`.

> نکته: GitHub Actions گاهی اجرا را تا چند دقیقه (حتی بیشتر) دیر شروع می‌کند.
